# Learnings

Skill-improvement log. Read at the start of every session and apply anything relevant. Append an entry whenever this run **deviates from the skill's instructions** or improvises in a way that turns out beneficial. Record only reusable, generalizable insights — tool quirks, better questions, rule refinements, validation gaps — **never** a specific person's CV content. These entries are the raw material for improving the skill's own instructions later.

## How to add an entry

```
### <date> — <short title>
- **Instruction said:** <what the skill's default was>
- **Did instead:** <what was actually done>
- **Why it helped:** <the benefit>
- **Generalize to skill?:** <yes/maybe/no — and which file/section it would touch>
```
